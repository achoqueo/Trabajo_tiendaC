# Estandares de Codigo y Clean Code

- **Nombres Explicitos:** Usar notacion camelCase para variables y funciones (`validarDocumentoUnico`, `datosCliente`). No usar abreviaturas ambiguas.
- **Principio de Responsabilidad Unica (SRP):** Las funciones deben ser pequenas y realizar una sola operacion.
- **Manejo de Errores Explicito:** Lanzar excepciones de negocio contextualizadas en lugar de retornar valores ambiguos.
